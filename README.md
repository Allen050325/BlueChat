# BlueChat

BlueChat is an experimental messaging platform built on Matrix.

## Current Prototype

- Matrix Synapse homeserver
- Element Web client
- Local Docker Compose deployment
- Test users:
  - @allen:localhost
  - @test:localhost
- Test room:
  - BlueChat Test Room

## Local URLs

- Element Web: http://localhost:8080
- Synapse API: http://localhost:8008

## Run

docker compose up -d

## Stop

docker compose down

## Status

Prototype v0.1 is running locally.
